# Professional GitHub Repository Setup

Independent portfolio demonstration for a fictional support team. Its queue summary arrived as three loose files. The original delivery is preserved in the first commit. The working tree now separates the script, sample queue and operating notes so another contributor can reproduce the result and trace each change.

## Try the handover

From the repository root, run `python src/summary.py examples/tickets.csv` with Python 3. The supplied queue contains two open items.
